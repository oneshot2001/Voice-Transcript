HTTP API Endpoints

All endpoints require digest authentication and are relative to /local/voice/

Endpoint Method Description
/speak POST Text-to-speech synthesis
Body: {"text":"..."}
/playback POST Play WAV from URL
Body: {"url":"..."}
/listen_start POST Start STT listening
/listen_stop POST Stop listening & get transcription
/transcription GET Get last transcription
Returns: {"text":"..."}
/status GET Stream status monitoring
/settings GET / POST Wyoming server configuration

MQTT Topics

Topics are auto-configured with device serial number: voice/{action}/{SERIAL}

Subscribe (Commands to device):
  • voice/speak/{SERIAL}
    Payload: {"text":"..."}
  • voice/playback/{SERIAL}
    Payload: {"url":"..."}
  • voice/listen/start/{SERIAL}
    Payload: {}
  • voice/listen/stop/{SERIAL}
    Payload: {}
Publish (Events from device):
  • voice/connect/{SERIAL}
    Published on startup with device info
  • voice/transcript/{SERIAL}
    Payload: {"text":"..."}
